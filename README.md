# 『ドパミン・パチンコ (Dopamine Pachinko)』企画・Steam販売ロードマップ

## 1. コンセプト定義
- **ジャンル**: 弾数インフレ × 物理パチンコ × ローグライク・クリッカー
- **コアターゲット**: ショート動画（TikTok/Shorts）世代、インフレ・快感重視のプレイヤー
- **想定販売価格**: 350円〜470円（Steam）

## 2. ショート動画（TikTok / YouTube Shorts）バズ戦略
1. **動画のフック（最初の1〜2秒）**:
   - 「1発落としただけなのに画面が玉で埋まってPCクラッシュ寸前www」
   - 「中央のx500ポケットに吸い込まれたときの音が気持ちよすぎる」
2. **音ハメ・ASMR訴求**:
   - Web Audioのペンタトニック音と爆発音の連鎖をそのままショート動画のBGMとして活用。
3. **SteamストアURLの導線**:
   - プロフィールリンクやコメント欄固定でSteamウィッシュリスト登録を促す。

## 3. Steam製品版（Unity / Godot版）への機能拡張案
- **新ボールタイプ**:
  - レーザーボール（ピンを貫通して消し去る）
  - ブラックホールボール（周囲のピンを吸い込んで一気に破裂）
  - コインボール（当たったピンを一定時間ゴールド化）
- **ボス / レイドターゲット**:
  - 画面上部から迫る巨大ターゲットを、下から跳ね返る弾幕で削り切るバトル要素
- **実績（Steam Achievements）**:
  - 「玉数 1,000発同時表示」
  - 「1回で1億スコア突破」
  - 「盤面全ピン破壊」
